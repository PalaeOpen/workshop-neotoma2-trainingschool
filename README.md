# workshop-neotoma2-trainingschool
Scripts and materials for the PalaeOpen Training School workshop "introduction to neotoma2" Sofia 16/06/26

This workshop has been built using [Quarto](https://quarto.org) which allows creating a html output file from the R scripts and visualize the embedded code and figures.   

To access to the repository, there are three options options (from easy to difficult)
  
1. Download the `intro_neotoma2.html` and copy-paste the code in your R Studio.
2. Download the **Quarto** file `intro_neotoma2.qmd` and run the R chunks in R studio. You can decide whether or not render it and obtain the html output file `intro_neotoma2.html`
2. Download the full repository in your local machine: Code > Download ZIP. Unzip the file and open `workshop-neotoma2-trainingschool.Rproj`
3. If you have a [GitHub account](https://github.com/) and can use [git](https://git-scm.com/), you can [clone the repo](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
