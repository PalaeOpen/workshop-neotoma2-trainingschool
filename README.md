# workshop-neotoma2-trainingschool
Scripts and materials for the PalaeOpen Training School workshop "introduction to neotoma2" Sofia 16/06/26

This workshop has been built using [Quarto](https://quarto.org) which allows create a html output file from the R scripts and visualize the embedded code and figures. The Quarto file follows PalaeOpen custom theme created by [Ondřej Mottl](https://github.com/OndrejMottl)    

To access to the repository, there are three options options:
  
1. Download the full repository in your local machine: Code > Download ZIP. Unzip the file and open `workshop-neotoma2-trainingschool.Rproj`
2. If you have a [GitHub account](https://github.com/) and can use [git](https://git-scm.com/), you can [clone the repo](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
3. Download only the **Quarto** file `intro_neotoma2.qmd` and render it in your R Studio. Alternatively, you can also download the quarto output html file and copy-paste the code in your R Studio (more time consuming)
